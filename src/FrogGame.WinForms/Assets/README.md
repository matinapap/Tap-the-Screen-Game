# Game assets

Images are loaded from this folder at runtime and copied next to `FrogGame.exe` on build.
Any image that is missing is skipped, so the game still runs without it.

| File               | Used for                                   |
| ------------------ | ------------------------------------------ |
| `title.gif`        | Main menu background                       |
| `lakeform1.gif`    | Level select and game over backgrounds     |
| `background3.jpg`  | Leaderboard background                     |
| `water.jpg`        | Level 1 background                         |
| `lake.png`         | Level 2 background                         |
| `frog.png`         | The frog target                            |
| `happy.png`        | The duck target (level 3)                  |
| `coin.png`         | Bonus coins                                |
| `wand1.png` – `wand3.png` | Mouse cursor for levels 1–3 and the level select preview |
